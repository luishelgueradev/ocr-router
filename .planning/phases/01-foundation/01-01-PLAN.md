| Boundary | Description |

| app → OCR provider (ocr.space / Ollama Cloud) | outbound HTTP with per-provider key |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-01 | Spoofing | bearer auth (lib/v1/auth.js) | mitigate | RFC 6750 case-insensitive scheme + crypto.timingSafeEqual (ported AS-IS) |
