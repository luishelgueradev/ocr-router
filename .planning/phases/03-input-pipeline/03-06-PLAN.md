This closes INP-06 and integrates INP-03/04/05/07/08 into the user-visible response envelope — reusing the Phase-2 cascade unchanged.

Purpose: This is where "the service accepts PDFs and extra formats and returns memory-safe per-page results" actually happens. It must extend the page-aware envelope additively without breaking any Phase-1/2 assertion.
Output: `lib/v1/input/page-pipeline.js`, a `runInputJob` branch in `worker.js`, and host tests (all decoders real, poppler stubbed).
</objective>
