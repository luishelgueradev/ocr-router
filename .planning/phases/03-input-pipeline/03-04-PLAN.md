<objective>
Build the PDF path in two host-testable modules: native per-page text extraction with a sufficiency threshold (the cheap fast path that skips OCR), and memory-safe single-page rasterization that reads page count via `pdfinfo` first (cap gate), then renders exactly one page to a captured PNG buffer through the sandboxed `spawnCapture` seam. Covers INP-03, INP-04, INP-07, and consumes the INP-08 seam.

Purpose: Most digital PDFs never need OCR (native text short-circuit); scanned pages must rasterize one-page-at-a-time with four layered decompression-bomb guards, never an all-pages temp explosion. poppler is Docker-only, so all subprocess calls go through the injectable seam and host tests stub it.
Output: `lib/v1/input/pdf-text.js`, `lib/v1/input/rasterize.js`, host tests (unpdf real, poppler stubbed), a tiny native-PDF fixture.
</objective>
