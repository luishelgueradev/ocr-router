<objective>
Extend the authoritative magic-byte sniffer and the accepted-type gates so PDF, multipage TIFF, HEIC/HEIF, BMP, and GIF uploads are recognised by their bytes and admitted to the worker, while spoofed/unknown inputs still get a typed 422. This is the front-door prerequisite that lets every new format reach the pipeline (INP-03/04/05).

Purpose: Today `sniffImage` only knows PNG/JPEG/WebP and `upload.js` fileFilter only allows those three declared mimetypes, so a PDF is rejected at the door. Type must be decided by magic bytes, never the client content-type (D-06 / INP-02 pattern).
Output: Extended `sniff.js`, `upload.js` fileFilter, `router.js` messaging, and updated sniff/upload tests.
</objective>
