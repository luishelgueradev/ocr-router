<objective>
Normalize every non-native image format (multipage TIFF, animated GIF, HEIC, BMP — plus straight-through PNG/JPEG/WebP) into an ordered array of routable normalized PNG frame buffers, one frame decoded in memory at a time, with a decompression-bomb guard on every decode. Covers INP-05 and the image side of INP-07. All decoders run in-process on the host (no subprocess), so this plan is fully host-tested for real.

Purpose: The cascade only routes plain images; TIFF/GIF are multi-frame and HEIC/BMP are undecodable by prebuilt libvips directly. This module turns any admitted image into page-aware frames the pipeline can route.
Output: `lib/v1/input/image-normalize.js` + real host tests with tiny multi-frame/HEIC/BMP fixtures.
</objective>
