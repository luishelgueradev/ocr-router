## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → subprocess | Untrusted document handed to a native renderer (poppler) in a child process |
| worker → filesystem | Per-job temp dir holding intermediate page files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | DoS (hung/looping renderer) | spawnCapture child | mitigate | AbortSignal binds child kill + `timeout -s KILL` wall-clock backstop + SIGTERM→SIGKILL escalation timer (Node has no built-in escalation) |
| T-03-05 | DoS (orphaned child after abort) | sh -c wrapper | mitigate | `exec` in the shell body so the signal reaches poppler directly; `tini` (PID 1) reaps any straggler |
| T-03-06 | Elevation/Tampering (malicious decoder) | poppler subprocess | mitigate | `ulimit -v` (address space) + `ulimit -t` (CPU sec) kernel-enforced caps; killed on deadline |
| T-03-07 | DoS (temp-file / disk exhaustion across deploys) | temp registry | mitigate | Registry drained by `drainAndCancel` on SIGTERM + `finally` cleanup per job; idempotent `force:true` rm (Pitfall 2) |
</threat_model>
